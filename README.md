# 患者案内システム

院内の患者呼び出し番号を表示・記録するスタンドアロン端末用アプリです。ブラウザだけで動作し、サーバーもデータベースも必要ありません。

## データの取り扱い

記録される情報（番号・終了時刻）は、**その端末のブラウザ内（localStorage）にのみ保存されます。** どこにも送信されません。

そのため次の点に注意してください。

- 端末をまたいだ共有はできません。2台で開くとそれぞれ別の状態になります。
- ブラウザの履歴・サイトデータを消すと記録も消えます。
- iOS/iPadOS では、**7日間まったく開かないと保存データが自動削除される**ことがあります（連休明けは番号が初期状態に戻ります）。

## GitHub Pages への公開手順

1. GitHubで新しいリポジトリを作り、このフォルダの中身をすべてアップロードします（`index.html` がリポジトリの最上位に来るようにしてください）。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** で `Deploy from a branch` を選び、Branch を `main` / フォルダを `/ (root)` にして **Save**。
4. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

> **公開範囲について**
> 無料プランでPagesを使う場合、リポジトリは公開（public）にする必要があり、**URLを知っている人は誰でもこの画面を開けます。** 患者データは端末内にしかないため情報漏洩にはなりませんが、気になる場合は有料プラン（Pro以上）で非公開リポジトリのままPages公開ができます。

## 端末へのインストール（アプリ化）

Pagesで公開したURLを端末のブラウザで開き、以下の操作をします。

- **iPad / iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
- **Android / PC（Chrome・Edge）**：アドレスバー右のインストールアイコン、またはメニュー →「アプリをインストール」

ホーム画面のアイコンから起動すると、アドレスバーのない全画面表示になります。一度読み込めば**オフラインでも起動します**（Service Workerがファイルを端末に保存するため）。

## 日々の運用

- 番号や終了リストは**診療日が変わると自動的に初期状態（01）に戻ります。** 手動でのリセットは不要です。
- 「診療日」の区切りは**午前4時**です。深夜0時をまたいで操作しても、前日の続きとして扱われます。
- 端末をつけっぱなしにしていても、翌朝画面を触った時点で自動的に切り替わります。
- 途中で番号をリセットしたい場合は、右下の「リセット」ボタンを使ってください。
- 右パネルには**直近6人分**の終了番号と終了時刻が表示されます。「一人当たりの目安」もこの6人分から算出しています。

## ファイル構成

```
index.html    アプリ本体（画面・処理・呼び出し音声をすべて内包）
manifest.json アプリ名やアイコンの定義（ホーム画面追加用）
sw.js         Service Worker（オフライン動作用）
icons/        アプリアイコン
.nojekyll     GitHub Pages の変換処理を無効化する印
```

外部ライブラリは一切使っていません。**このアプリはネット接続なしで完全に動作します。**

## 修正したときの注意（重要）

`index.html` などを修正して再アップロードしたら、**必ず `sw.js` の先頭にある `CACHE_VERSION` の数字を1つ増やしてください。**

```js
const CACHE_VERSION = 'v1';  // → 'v2' に変更する
```

これを忘れると、端末が保存済みの古い画面を表示し続け、修正が反映されません。

反映されない場合は、アプリを一度閉じて開き直すか、ブラウザで開いて再読み込みしてください。
